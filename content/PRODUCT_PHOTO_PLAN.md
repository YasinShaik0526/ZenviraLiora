# Product Photo Plan

Prepare approved images for every SKU using the SKU as the filename prefix.

## Required views

- `{SKU}-front.jpg`: clean full-product view
- `{SKU}-back.jpg`: clasp, closure, and reverse finish
- `{SKU}-detail.jpg`: stones, texture, and workmanship
- `{SKU}-model.jpg`: worn scale and proportion
- `{SKU}-variant-{name}.jpg`: each approved colour or finish variant
- `{SKU}-packaging.jpg`: supplied box, pouch, and included pieces

## Missing flyer collections

- Kids Collection

Review whether the current ring photography is approved for the CZ Collection before publication.

## Capture requirements

- Use consistent neutral lighting and an uncluttered background.
- Keep the entire piece sharp and avoid filters that alter colour.
- Include a scale reference or model view where sizing matters.
- Record photographer approval and usage rights with each delivery.
- Export a high-quality source image; the repository optimizer will create web-ready derivatives.
